# ZORIX — Custom Commerce

A custom-built fashion and everyday essentials storefront for ZORIX.

## Tech stack

- Next.js App Router
- React + TypeScript
- Tailwind CSS v4
- Lucide icons

## Getting started

1. Install Node.js 20.9 or later.
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
4. Open http://localhost:3000

## Available scripts

- `npm run dev` — local development
- `npm run build` — production build
- `npm run start` — run production server
- `npm run lint` — lint the codebase
- `npm run typecheck` — TypeScript validation

## Project status

The initial storefront foundation is in place. Product data, authentication, admin tools, checkout, order management, and database integration will be added in subsequent development stages.

## Brand direction

ZORIX uses an original visual identity and a premium, editorial fashion-store layout. Reference sites are for design direction only; third-party branding and photography are not copied.
